# Personal Finance Tracker - SQL Database Project

## About
A personal finance tracking system built using MySQL that helps track daily expenses, manage monthly budgets, and analyze spending patterns.

## Tools Used
- Database: MySQL 9.7
- Interface: MySQL Workbench 8.0

## Database Tables

1. categories - Stores expense categories like Food, Travel, Rent
2. transactions - Stores every single expense made
3. budgets - Stores monthly budgets for each category

## Analysis Queries

1. How much did I spend on each category?
2. Which payment mode do I use the most?
3. Did I overspend my budget this month?
4. How much did I spend in total this month?
5. Which day did I spend the most?
6. Monthly spending summary

## SQL Concepts Used
- CREATE TABLE, PRIMARY KEY, FOREIGN KEY
- INSERT, DELETE, UPDATE
- SELECT, WHERE, GROUP BY, ORDER BY, HAVING
- INNER JOIN across multiple tables
- SUM(), COUNT(), MONTH(), YEAR()
- Views for reusable reporting
